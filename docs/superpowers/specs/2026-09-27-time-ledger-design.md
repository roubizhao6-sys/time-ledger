# 时光存折 — 产品设计规格

## 1. 产品定义

时光存折是一个面向中国大陆年轻人的本地优先记忆服务系统。

用户每月花1分钟存入一张照片和一句话，系统自动形成时间轴、连续记录、月度小结和年度数字回忆册。

核心承诺：

> 每月存一点，年底得到一本只属于你的年度回忆册。

## 2. 用户与场景

目标用户：

- 18—35岁中国大陆用户
- 情侣、异地恋、闺蜜、家庭成员、独居年轻人
- 想记录生活，但不愿每天写长篇日记的人
- 想为生日、纪念日、毕业、旅行或人生阶段留下记录的人

典型场景：

- 每月记录一张生活照片
- 情侣共同记录关系时间轴
- 家庭成员共享年度记忆册
- 给一年后的自己留下成长轨迹
- 年底生成可打印、可保存的数字回忆册

## 3. 核心价值

实际价值：

- 降低记录门槛
- 自动按时间整理
- 本地保存，不依赖平台
- 可加密备份和迁移设备
- 自动生成年度数字回忆册
- 提供月度提醒日历

情绪价值：

- 被记住
- 有仪式感
- 看见自己的变化
- 与重要的人共同积累
- 年底获得一个完整成果

## 4. 为什么不是普通AI产品

普通AI可以生成文字，但不会：

- 持续保存用户一年里的私人记忆
- 维护时间轴和连续记录
- 自动生成月度小结和年度册
- 支持本地加密备份
- 支持情侣或家庭共享文件
- 形成用户自己的长期数据资产

产品的护城河是用户持续积累的个人数据、习惯和年度成果，不是模型能力。

## 5. 商业模式

- 免费版：最多3条记忆，基础时间轴
- 月度版：¥9.9/月，不限记忆、月报、提醒日历、加密备份
- 年度版：¥79/年，不限记忆、年度册、更多主题、优先支持
- 双人或家庭版：¥19.9/月，最多4人通过加密文件共享空间

本地优先MVP不接入真实自动续费。付款通过个人微信人工确认，激活码由本地发码工具签发。

## 6. 本地优先原则

MVP默认不上传用户内容到服务器。

- 数据保存在浏览器IndexedDB
- 图片在本地压缩后存储
- 备份导出为加密文件
- 换设备通过加密文件导入
- 用户可一键删除全部本地数据
- 不把“本地保存”宣传成永久云备份

## 7. 系统架构

前端：

- React + TypeScript + Vite
- Hash Router，兼容GitHub Pages
- IndexedDB持久化
- Web Crypto加密备份
- PWA离线访问

主要模块：

1. 欢迎与引导
2. 仪表盘
3. 新增记忆
4. 时间轴
5. 记忆详情
6. 年度回忆册
7. 共享空间
8. 加密备份与恢复
9. 提醒日历
10. 订阅与激活
11. 设置与隐私
12. 帮助中心

## 9. 核心流程

首次使用：

1. 欢迎页说明产品价值
2. 创建存折
3. 选择个人、情侣或家庭
4. 存下第一条记忆
5. 进入仪表盘

月度使用：

1. 打开仪表盘
2. 看到本月提示和连续记录
3. 点击“存入一笔”
4. 上传一张照片、写一句话、选择心情
5. 保存后看到进度反馈

年度使用：

1. 进入年度册
2. 生成封面、统计和月度亮点
3. 导出HTML年度册
4. 可打印或分享给授权的人

换设备：

1. 导出加密备份
2. 在新设备导入
3. 输入备份密码
4. 恢复存折和记忆

## 10. 激活码设计

为了支持线下微信收款，使用离线激活码：

- 应用内置ECDSA公钥
- 发码工具使用私钥签发
- 激活码包含设备ID、版本和到期时间
- 应用验证签名并检查设备ID
- 私钥保存在本地`private/`目录，不进入公开仓库

激活流程：

1. 用户复制自己的设备ID
2. 微信发送设备ID并付款
3. 卖家运行本地发码命令
4. 用户输入激活码

## 11. 错误处理

- IndexedDB不可用：提示使用无痕模式或更换浏览器
- 图片过大：压缩到最大1600px，单张不超过3MB
- 导入文件损坏：提示文件无效，不覆盖现有数据
- 密码错误：提示密码错误，保留当前数据
- 激活码失败：区分过期、设备不匹配、签名无效
- 数据为空：展示引导和示例内容
- 存储空间不足：提示导出并删除旧数据

## 12. 隐私与安全

- 不要求账号密码
- 不默认上传照片和文字
- 备份文件使用AES-GCM加密
- 密码不保存到服务器
- 删除操作需要二次确认
- 不承诺绝对安全或永久保存
- 用户自行保存备份文件

## 13. 设计与体验原则

- 像存折，不像复杂SaaS后台
- 首页只有一个主行动：存入一笔
- 每屏只强调一个结果
- 用“余额、存入、连续、年度结算”建立熟悉心智
- 透明展示价格、取消方式和数据控制权
- 不使用虚假原价、假稀缺、假倒计时
- 默认值合理，用户无需理解技术细节

## 14. MVP验收标准

- 用户可创建存折
- 用户可新增、编辑、删除记忆
- 图片可本地压缩保存
- 时间轴可按年份和标签筛选
- 连续记录计算正确
- 可导出加密备份并成功恢复
- 可生成并下载年度HTML回忆册
- 可生成12个月提醒日历
- 免费版最多3条记忆
- 激活码可离线验证
- GitHub Pages可访问
- 手机和桌面端可用
